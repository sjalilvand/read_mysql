# 🧠 سامانه گزارش‌گیری و تحلیل — راه زندگی

برنامه کامل **داشبورد مدیریتی BI + گزارش‌ساز + مرور داده‌ها + استعلام مددجو**
برای بکاپ MySQL **سامانه مراکز خدمات روانشناسی و مشاوره راه زندگی** —
ساخته‌شده بر پایه ساختار واقعی دیتابیس (۷۵ جدول) و صفحات برنامه اصلی.

---

## ⚡ اجرا (ویندوز)

1. پایتون ۳.۱۰ یا بالاتر (اگر ندارید):
   ```powershell
   winget install -e --id Python.Python.3.12
   ```
2. پوشه برنامه را در `D:\Projects\rahe_zendegi` قرار دهید.
3. اجرا:
   ```powershell
   cd D:\Projects\rahe_zendegi
   .\start.ps1
   ```
   (اگر PowerShell اجازه نداد: `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` و دوباره اجرا کنید،
   یا روی `run.bat` دابل‌کلیک کنید.)

مرورگر خودکار روی `http://127.0.0.1:5000` باز می‌شود.

## 📦 انتخاب منبع داده (اولین اجرا)

در صفحه «منبع داده و ایمپورت» سه حالت دارید:

| حالت | توضیح |
|---|---|
| **دیتابیس آماده** | اگر قبلاً با `sql_viewer` بکاپ را استخراج کرده‌اید
(`D:\Projects\sql_viewer\viewer_data\parsed.sqlite`)، همان را انتخاب کنید — **بدون نیاز به استخراج مجدد!** |
| **فایل بکاپ SQL** | مسیر `D:\Projects\sql_viewer\app2_backup_202611031659.sql` به‌طور خودکار پیدا می‌شود؛
دکمه «استخراج از این بکاپ» را بزنید (فایل ۱٫۴ گیگابایتی چند دقیقه طول می‌کشد) |
| **داده نمونه** | برای آشنایی با امکانات، بدون نیاز به بکاپ واقعی |

بعد از ایمپورت، دکمه **«ساخت ایندکس‌ها برای سرعت»** را بزنید تا گزارش‌ها روی دیتابیس بزرگ سریع شوند
(یک‌بار انجام می‌شود).

## 🧩 امکانات

### 📊 داشبورد مدیریتی BI
- ۸ کارت KPI: کل جلسات، انجام‌شده، ناتمام، موارد حاد، مراجعان یکتا، مشاوران فعال،
  جمع حق‌الزحمه‌ها، رزروها
- ۱۵ نمودار: روند ماهانه جلسات (تقویم شمسی)، نوع خدمت، استان‌ها، مراکز پرتقاضا،
  وضعیت تایید ۵ مرحله‌ای، جنسیت/تاهل/تحصیلات مراجعان، مشاوران پرکار،
  موارد حاد (شدت خطر/وضعیت)، رشد ثبت‌نام، ارجاعات سها، پیامک‌ها، جلسات گروهی
- جدول سهمیه‌های بودجه با درصد مصرف
- فیلتر استان + بازه تاریخ شمسی؛ خروجی CSV برای هر نمودار

### 🧾 گزارش‌ساز
- **۱۶ گزارش آماده** مطابق صفحات برنامه اصلی: جلسات انجام‌شده/ناتمام، جلسات گروهی
  انجام‌شده/ناتمام (با تعداد حاضران)، عملکرد مالی به تفکیک مشاور، به تفکیک خدمت‌گیرنده،
  ارجاعات سها، درخواست‌های رزرو، موارد حاد، بررسی مشاوره‌ها (تایید ۵ مرحله‌ای)،
  کاربران معرفی‌شده، فعالیت کاربران، کاربران، مالیات مشاوران، سهمیه‌ها، رزروها
- همه فیلترهای همان صفحه اصلی: استان → شهرستان (وابسته)، مرکز، مشاور، خدمت،
  جنسیت، وضعیت تایید، کیس حاد، بازه تاریخ شمسی…
- خروجی **CSV** (سازگار با اکسل فارسی) و **اکسل xlsx** (راست‌به‌چپ) و چاپ/PDF
- **سازنده آزاد**: انتخاب جدول از ۷۵ جدول، انتخاب ستون‌ها با برچسب فارسی،
  فیلترهای چندگانه (۱۰ عملگر)، گروه‌بندی + تجمیع (تعداد/جمع/میانگین/کمینه/بیشینه)،
  گروه‌بندی ماه شمسی، مرتب‌سازی، جستجوی سراسری، ذخیره گزارش‌های شخصی

### 🗄️ مرور داده‌ها
- هر ۷۵ جدول با نام فارسی، شمارش ردیف‌ها، جستجو، مرتب‌سازی، صفحه‌بندی و خروجی CSV
- اتصال خودکار کلیدهای خارجی: به‌جای شناسه، **نام** مراجع/مشاور/مرکز/خدمت نمایش داده می‌شود
- تاریخ‌ها به **تقویم شمسی**، ارقام فارسی، ترجمه همه کدهای وضعیت به فارسی

### 🔍 استعلام مددجو
با کد ملی: پروفایل + نقش‌ها + جلسات (با شمار تاییدها) + موارد حاد + ارجاع‌ها +
رزروها + پیامک‌ها + مالیات + مشاوره شغلی — همه در یک صفحه

### 🔒 امنیت داده
ستون‌های محرمانه (هش رمز عبور، کلید نشست، توکن‌ها…) **هرگز** نمایش یا خروجی داده نمی‌شوند.

```
├── bi.py             ← کوئری‌های داشبورد BI
├── jalali.py         ← تقویم شمسی سمت سرور
├── dump_parser.py    ← پارسر استریمی بکاپ MySQL (مناسب فایل چند گیگابایتی)
├── templates/        ← رابط کاربری راست‌به‌چپ (تم رز، حالت شب)
├── static/           ← استایل + نمودارهای SVG بدون اینترنت
├── scripts/          ← تست خودکار (۱۰۵ آزمون) و داده نمونه
└── test/             ← بکاپ نمونه برای تست
```

## 🛠 تغییرات نسخه ۱٫۳
- **رفع خروجی اکسل و CSV:** دکمه‌های «خروجی CSV/اکسل» در گزارش‌های آماده به مسیر درست وصل شدند (قبلاً JSON خام به‌جای فایل ذخیره می‌شد). موتور داخلی ساخت XLSX هم اضافه شد که حتی بدون openpyxl فایل اکسل سالم و راست‌به‌چپ می‌سازد.
- **رفع باگ فیلترها:** فیلتر «شامل/برابر» در گزارش‌ساز و فیلتر ستونی به‌دلیل خطای تبدیل عملگر نادیده گرفته می‌شد — اکنون همه عملگرها کار می‌کنند.
- **مرور داده‌ها:** فیلتر جداگانه برای هر ستون (شامل تاریخ شمسی: «۱۴۰۴/۰۷» یا «۱۴۰۴»)، مرتب‌سازی، صفحه‌بندی کامل (اول/قبلی/بعدی/آخر + شماره صفحه‌ها + اندازه صفحه ۲۵ تا ۵۰۰) و خروجی CSV/اکسل از همان نتیجه فیلترشده.
- **داشبورد:** تفسیر خودکار زیر هر نمودار (سهم بیشترین، روند، اوج، نرخ انجام)؛ ذخیره و بارگذاری داشبوردهای شخصی؛ سنجاق نمودارهای گزارش‌ساز به داشبورد.
- **database_structure.txt:** ساختار کامل ۷۵ جدول (ستون‌ها، نوع‌ها، روابط، ردیف‌های واقعی) کنار برنامه تولید می‌شود: `python scripts\make_structure_txt.py`

## 🛠 تغییرات نسخه ۱٫۲
- **رفع اشکال بسته‌بندی:** فایل zip اکنون مانند نسخه ۱٫۰ پوشه `rahe_zendegi` را در ریشه دارد؛ استخراج در `D:\Projects` فایل‌ها را درست داخل پوشه برنامه می‌ریزد (در بسته ۱٫۱ فایل‌ها اشتباهاً در خود `D:\Projects` پخش می‌شدند و برنامه به‌روز نمی‌شد).
- نسخه‌گذاری فایل‌های استاتیک (`?v=12`) برای جلوگیری از کش شدن قدیمی `app.js` در مرورگر.

## 🛠 تغییرات نسخه ۱٫۱
- **رفع اشکال مهم:** دکمه‌های صفحه «منبع داده و ایمپورت» (استفاده از دیتابیس / استخراج از بکاپ / ساخت ایندکس‌ها) کار نمی‌کردند — اتصال رویداد کلیک در جاوااسکریپت به عنصری وابسته بود که در صفحه وجود نداشت. اکنون دکمه‌ها مستقیماً شناسایی و متصل می‌شوند.
- پیام خطای واضح در صورت قطع ارتباط با سرور به‌جای بی‌反应 بودن دکمه.
- پایدارسازی نمایش پیشرفت عملیات در صورت خطای شبکه.
